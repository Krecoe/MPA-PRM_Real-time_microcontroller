# Code style
- Write the simplest code that solves the task.
- Prefer plain functions and a straightforward top-to-bottom flow.
- Use clear, descriptive names. Comment only on why something is done, or on a non-obvious formula.

# Tools
- Prefer a library function over reimplementing it, unless the assignment says to implement it.

# Evaluation
- Start with a simple baseline before trying anything more complex.

# Workflow
- Run the code before saying it works, and show the actual output.
- Never make up metrics or claim results you did not get.
